# إدارة القواعد — تحديث 2026-11-04

## المنفذ والمختبر

- تظهر نافذة إدارة القواعد قبل الدخول: قائمة، فتح، إنشاء جديد، إضافة موجودة، إلغاء، وتحديث.
- يعرض السجل الاسم الوصفي، ويظهر اسم قاعدة SQL عند تحديده.
- يمكن تغيير عنوان خدمة موبي ستور. بيانات اتصال SQL تبقى على السيرفر.
- إنشاء قاعدة مستقلة على نفس SQL Server المتصل به السيرفر، ثم إعداد المنشأة والعملة USD/SYP وحساب المدير عند فتحها أول مرة.
- الإضافة تسجل قاعدة موبي ستور موجودة ومتوافقة على نفس SQL Server؛ لا تلحق ملف MDF ولا تستورد قاعدة برنامج آخر.
- قبول أسماء MobiStore_ فقط مع حروف إنكليزية وأرقام وشرطة سفلية. لا تُستبدل قاعدة موجودة عند الإنشاء.
- إعداد فتح آخر قاعدة تلقائيًا اختياري وغير مفعّل افتراضيًا. تحفظ معلومات العنوان والاسم فقط في LocalApplicationData/MobiStore/database-selection.json؛ لا تحفظ كلمات مرور أو جلسات.
- سجل القواعد database-catalog.json في مجلد خدمة السيرفر، ويضم قاعدة الاتصال الافتراضية تلقائيًا.
- الكاشيرات تستطيع سرد القواعد وفتحها؛ الإنشاء والإضافة عبر الخدمة مقيدان باتصال loopback من جهاز السيرفر. حساب تشغيل الخدمة يحتاج صلاحية SQL المناسبة لإنشاء قاعدة.
- كل طلب يحمل اسم القاعدة المسجلة، وتُقرأ جلسة الدخول من نفس القاعدة. لا يجيز رمز جلسة لقاعدة الوصول إلى قاعدة ثانية.
- بعد المصادقة يجلب البرنامج بيانات المستخدم الحالية وصلاحياته والمنشأة، ثم يحمل المواد والعملاء والمستودعات قبل إتاحة الواجهة. هذا تحميل من السيرفر المحلي؛ لا توجد مزامنة دون اتصال.

## التحقق

بناء السيرفر وويندوز والاختبارات دون أخطاء أو تحذيرات. نجح 47 اختبارًا على SQL Server Express، تشمل إنشاء قاعدة أخرى بعملة مختلفة، عدم استبدال قاعدة موجودة، عزل الرموز بين القواعد، منع اختيار قاعدة غير مسجلة، واستمرار اختبارات المخزون والقبض وإغلاق الصندوق.

راجعت نافذة الاختيار بصريًا على الجهاز: القائمة والاسم وأزرار الإجراءات كاملة ظاهرة. لا يعني هذا التحقق اعتماد المنظومة للإنتاج.

## المتبقي من المرجع المتفق عليه

- معالج متعدد الصفحات لاختيار SQL instance والمصادقة واختبارها، ومسارات ملفات القاعدة على السيرفر.
- أدلة حسابات متعددة ولغات ونوع نقطة البيع ومراجعة الإعدادات قبل الإنشاء.
- نافذة دخول فوق الواجهة الرئيسية، واختيار مستخدم من قائمة.
- القوائم العلوية والاختصارات وتخطيط الرئيسية حسب المرجع.
- نسخ احتياطي واستعادة وترقيات مخطط معتمدة. التسجيل الحالي لا يرقّي قاعدة قائمة.

النافذة الحالية جزء عامل من المسار؛ بقية الخطوات أعلاه ما زالت مخططة.
