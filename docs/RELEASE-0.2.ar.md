# موبي ستور 0.2 — تحديث 2026-11-04

## التشغيل والإضافات

افتح `Start-MobiStore.cmd` ثم اختر القاعدة وسجّل الدخول بحسابك الحالي. لا توجد كلمة مرور افتراضية، وكلمات المرور المخزنة بصمات PBKDF2 لا يمكن استخراجها كنص.

### المواد والعملاء

- من «المواد والمستودعات» اختر المادة ثم «تعديل المادة والصورة والتوافق».
- احفظ الماركة والهواتف المتوافقة واللون وأسعار المفرق والجملة. تعديل الأسعار والتفاصيل في طلب واحد ومعاملة واحدة.
- اختر صورة PNG/JPEG من الجهاز بحجم حتى 2 ميغابايت، أو أدخل رابط HTTPS. الصور المرفوعة محفوظة داخل قاعدة البيانات وتدخل نسخ SQL الاحتياطية.
- خيار نشر المادة متاح لمن يملك صلاحية النشر. الكتالوج يعرض المواد المنشورة فقط، مع سعر المفرق بالعملة الأساسية، دون التكلفة أو الكمية.
- من العملاء اختر عميلًا وافتح «أسعار خاصة». السعر الخاص للقطعة الأساسية ويُحسب سعر الوحدات الإضافية بمعاملها. يبقى آخر سعر بيع مرجعًا منفصلًا.

### الكاشير

- امسح الباركود واضغط Enter لإضافة المادة. تكرار نفس الوحدة بالسعر نفسه يجمع كميتها.
- F2 للباركود، F8 لتعليق الفاتورة، F9 للحفظ والترحيل.
- الفواتير المعلقة محفوظة لكل مستخدم على حدة ولا تؤثر في المخزون. عند استرجاعها يراجع الخادم المخزون والصلاحيات عند الترحيل.
- تخفيض سعر الوحدة لا يتجاوز فحص الخصم: يتحقق الخادم من السعر الخاص أو الجملة أو المفرق والحد المسموح للمستخدم.

### المخزون والموردون

- تحويل بين مستودعين يحافظ على إجمالي الكمية ولا ينشئ بيعًا أو دين عميل.
- الجرد للمدير: الرصيد المتوقع مقابل العدد الفعلي، مع بيان تسوية. يرفض الجرد إذا تغير الرصيد منذ فتحه، ويسجل قيد العجز/الفائض بالقيمة.
- كشف مستقل لكل اسم مورد من حركات الشراء والمرتجعات والدفعات. استخدم الاسم نفسه لتجميع حركات المورد.
- مرتجع الشراء مرتبط بالأصل وبسعر صرفه، ولا يتجاوز المتبقي أو رصيد المستودع. يمنع المرتجع الذي ينتج قيمة مخزون غير متسقة مع المتوسط الحالي ويطلب مراجعة المحاسب. لا يقبض نقدًا تلقائيًا من المورد.
- المدير يدفع للمورد من صندوقه المفتوح بحد الرصيد المستحق والنقد المتاح بنفس العملة. الإغلاق ينقل صافي الصندوق بعد الدفع، دون إعادة إثبات الحركة.

### الإدارة والصلاحيات

- تعديل اسم المستخدم وصلاحياته وحد الخصم أو إيقاف حساب موظف، مع سبب تعديل. تنتهي جلساته القائمة فور التعديل.
- تعطيل المدير من هذه النافذة غير مسموح، ولا تغيّر النافذة صفة المدير.
- سعر صرف حالي محفوظ. يبقى سعر كل فاتورة أو إيصال قديم ثابتًا.
- سجل العمليات يعرض المستخدم والتاريخ والنوع والتفاصيل، بما فيها أسباب الجرد وتعديل المستخدم.

### النسخ الاحتياطي حسب المسار الذي تختاره

من «الصيانة وسجل العمليات»:

1. اكتب مسار المجلد الكامل على السيرفر أو اضغط «اختيار مجلد».
2. احفظ المسار. يجب أن يكون المجلد موجودًا وقابلًا للكتابة لحساب خدمة SQL Server.
3. اضغط «إنشاء نسخة احتياطية وفحصها». تُنشأ نسخة COPY_ONLY مع CHECKSUM ويُنفذ RESTORE VERIFYONLY.
4. «اختبار الاستعادة» يستعيد آخر نسخة إلى قاعدة جديدة باسم MobiStore_RestoreTest ومعرّف عشوائي، دون استبدال الأصل. تُترك للمراجعة ولا تُحذف تلقائيًا.

المسار مستقل لكل قاعدة، ويستخدمه النسخ التلقائي أيضًا. المسار الفارغ يستخدم مجلد نسخ SQL الافتراضي. خدمة السيرفر تفحص كل 30 دقيقة، وتنشئ نسخة إذا مضت 24 ساعة على آخر نسخة ناجحة، طالما خدمة موبي ستور تعمل. لا توجد سياسة حذف تلقائي للنسخ ولا نسخة خارج السيرفر ما لم تحدد لها لاحقًا مسار شبكة مناسبًا. لم تُضبط صلاحيات Windows أو الجدار الناري آليًا.

عند ترقية قاعدة قديمة تضاف AppRecords فقط. تؤخذ نسخة SQL قبل الإضافة إذا كانت المنشأة مهيأة. لا يُعاد إنشاء الجداول المالية ولا تُستورد بيانات البرنامج المرجعي.

### الكتالوج وواجهة الهاتف

- `/catalog`: كتالوج عرض متجاوب مع بحث بالاسم والماركة والتوافق. افتحه من أدوات البرنامج ليحمل اختيار القاعدة نفسه.
- `/mobile`: واجهة ويب متجاوبة للمتابعة من متصفح الهاتف، مع حسابات العملاء وكشوفهم والفواتير والاستحقاقات والمؤشرات. التحصيل للمدير فقط على صندوقه، ويعرض الإيصال برقم فريد مع زر طباعة/حفظ PDF عبر المتصفح.
- الجلسة في ذاكرة الصفحة، ولا تُحفظ كلمة السر أو رمز الدخول في التخزين المحلي للمتصفح.
- هذه واجهة هاتف عبر الويب، وليست حزمة Android/iOS أصلية منشورة. الوصول من خارج المحل والنطاق وHTTPS والربط الشبكي مؤجلة بطلب المستخدم، والخدمة حاليًا محلية.

### إعلان المواد الجديدة

اختر تاريخًا ثم مواد أُدخلت منذ تفعيل هذا التحديث، وحدد بعض المستلمين أو الجميع. المعاينة تتضمن الاسم والسعر وروابط الصور دون الكميات. زر كل مستلم يفتح واتساب برسالة جاهزة، ويتطلب الضغط على الإرسال داخل واتساب. لا يرسل البرنامج تلقائيًا ولا يرفع الصور كمرفقات أو ينفذ حملات عبر API. الرقم التجاري والربط الخارجي مؤجلان بطلب المستخدم. أرقام المستلمين تُدخل مع رمز الدولة.

## التحقق والحدود

نجح 88 فحصًا على SQL Server Express ببيانات مصطنعة، منها ثلاثة كاشيرات مستقلين يتنافسون على آخر قطعة، وعزل القواعد والجلسات، وتكرار الطلبات والجرد والتحويل والمرتجعات ودفع المورد وصافي الإغلاق، وصور وكتالوج بلا كميات أو تكلفة، ومسار نسخ يدوي، واستعادة فعلية لقاعدة منفصلة. نجح بناء السيرفر وويندوز دون أخطاء أو تحذيرات. روجعت صفحة الكتالوج وصفحة دخول الهاتف بصريًا دون إدخال حسابات المستخدم.

تبقى هذه نسخة تطوير. لم تكتمل المنظومة المرجعية كلها: منها ضوابط إلغاء وتعديل الفواتير المعتمدة، طباعة كل أنواع المستندات، صرف مرتجع نقدي، الرواتب المعتمدة وصرفها والبصمة، كامل القوائم والتقارير المالية وفروق الصرف، تطبيقات أصلية للهاتف، وربط واتساب الآلي. مصدر متطلبات النطاق الواسع هو `VIDEO-SCOPE.ar.md`؛ هذه الإضافات لا تعني إكمال جميع عناصره.
